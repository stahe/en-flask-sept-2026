## Overview

This course provides a step-by-step guide to building an MVC web application using the **Flask** (Python) framework. The HTML pages are generated by the server using **Jinja2** views, without a client-side JavaScript framework.

It follows the course [Step-by-Step Introduction to the [Spring MVC](https://stahe.github.io/en-springmvc-sept-2026/) Web Framework], and follows the exact same progression. That course itself followed the courses [ASP.NET Core MVC](https://stahe.github.io/aspnetcoremvc-sept-2026/) and [NestJS](https://stahe.github.io/nestjs-html-sept-2026/). The examples have the same numbers and cover the same topics: a reader familiar with one of these courses can compare the frameworks example by example.

The course is divided into two parts:

- **28 short examples**, each focused on a specific concept:
  - actions, routing, responses, and redirects;
  - parameter binding and validation (Pydantic);
  - Jinja2 views, templates, and macros;
  - WTForms forms, Post/Redirect/Get pattern, and CSRF protection;
  - internationalization;
  - data scopes;
  - request lifecycle;
  - JWT authentication, roles, and CAPTCHA;
  - Layered architecture with SQLAlchemy and MySQL.
- **A complete case study**: *RdvMedecins*, an appointment scheduling application for a medical practice. It features three user roles (administrator, doctors, patients), operates in French and English, and is protected against bots. All of its files are commented on in the course.

## Technologies

Python 3.12+ · Flask 3.1 · Jinja2 · Werkzeug · Flask-WTF / WTForms · Pydantic · SQLAlchemy 2.1 · PyMySQL · PyJWT · bcrypt · Babel · waitress · Bootstrap 5.3 · MySQL 8 / MariaDB

## Prerequisites

- Python 3.12 or newer;
- Visual Studio Code, with the “Python” extension from Microsoft;
- MySQL 8 (for example, with Laragon on Windows) or MariaDB;
- curl.

Installation instructions for these tools are provided in the course appendices.
